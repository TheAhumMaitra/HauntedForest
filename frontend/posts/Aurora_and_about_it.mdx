Recently I tried make my own Hyprland pre-configured setup. Well much inspired from other setups, such as KoolDotz by Linux Foundation, ML4W, some design stylings and ideas from DHH's Omarchy. I don't have much users on it perhaps people don't know about it, haha. I'm personally using Aurora for my daily drive, and  I enjoy with it. I like how it fits my taste, but I should be asking **does that fit your test?**

Well, I can't answer that but perhaps I can know the majority people's _opinion_ and what they think about it (Hyprland users ofc and ordinary Linux users); for that I need to market it more but in this article, I will try my best to clarify some of the things about this, which might be concerned later if people start to use this :)

## Q1: Why should I use it?
Well, personally **_if it fits your taste then use it, it's free lol_** but here are some reasons :-

1. _Unique features from other setups_
2. _Uses Rust for it's scripts, cli, most tools; and that makes it fast to use_
3. _Has many `eye candy` type features_

Now these are not the most strongest point out there to decide you should or not but my philosophical truth about _Setup Hooping_ is to **try** it first! SO try it, it is available for **NixOS**, **Arch Linux and Arch based distros (most)**, **Fedora**.

Aurora might be your choice.

## Q2: Does it do vibe coding
Honestly, yes it does but not in every part, as all modern developers does; but if you hate vibe coding then I won't force you to use it.

It mostly does for Rust programming of certain things

## Q3: Does it support many distributions?

For yet, _NO_. But maybe one day, it will be like KoolDotz by LinuxFoundation

_**Note:**_ It only supports 3 distributions natively.

## Q4: Is it lightweight?
It depends on what do you mean for "lightweight". If any software or setup or regards that is less than 300mb is lightweight, then sure it is

## Q5: Is it copy of Omarchy?
As any wise man can observe that I toook inspiration from many Hyprland pre-configured setups not just Omarchy but it also has some unique features which Omarchy or others doesn't.

## Q6: Is it free?
Yes, forever
