Aurora is a fast, elegant, minimal Hyprland rice. Aurora can be installed via the installation script for Arch Linux. Aurora uses Rust for all of the scripts. It also uses new Lua support of Hyprland. It also includes a useful cli, theme switcher, some more utils. Aurora's theme switcher supports all core essentials with support of VS Code, Neovim; I will support Zed as soon as possible! Personally, Aurora's workspace designed to be all users! For yet, I included some useful tui's for ease of use. Aurora was inspired by Kooldots, old Omarchy (appearance only), ML4W.
